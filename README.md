# প্রতিদিনের দোয়া ও হাদিস

প্রতিদিনের দোয়া, সহিহ হাদিস ও কুরআনের আয়াত — আরবি মূলপাঠ, বাংলা উচ্চারণ ও অর্থসহ।
এই রিপোজিটরিতে অ্যাপটির সম্পূর্ণ কোড আছে, আর GitHub থেকেই Android APK বানিয়ে ফোনে ইনস্টল করা যায়।

## ফোনে ইনস্টল করার জন্য APK বানানো (সহজ ধাপে)

1. GitHub অ্যাপে (বা github.com-এ) এই রিপোজিটরি **Protidiner-Dua-Hadis** খুলুন।
2. উপরের **Actions** ট্যাবে যান।
3. বাম পাশের তালিকা থেকে **Build Android APK** বেছে নিন।
4. ডান পাশে **Run workflow** বোতামে চাপ দিন, তারপর সবুজ **Run workflow** বোতামটি আবার চাপুন।
5. বিল্ড শেষ হতে কয়েক মিনিট অপেক্ষা করুন। তালিকায় সবুজ টিক (✓) এলে বুঝবেন তৈরি হয়ে গেছে।
   (নতুন কোড এলেও বিল্ড নিজে নিজে শুরু হয়; তবে হাতে চালানোই সবচেয়ে নির্ভরযোগ্য।)
6. শেষ হওয়া বিল্ডটিতে ঢুকুন, নিচে **Artifacts** অংশে **Protidiner-Dua-Hadis-APK** নামে একটি ফাইল পাবেন — সেটি ডাউনলোড করুন।
7. ডাউনলোড করা zip ফাইলটি খুললে ভেতরে **app-debug.apk** পাবেন। সেটিতে চাপ দিয়ে ইনস্টল করুন।
   ফোনে "অজানা অ্যাপ ইনস্টল" (Install unknown apps) অনুমতি চাইলে Allow দিন — এটি আপনার নিজের বানানো অ্যাপ।

## অ্যাপে যা যা আছে

- প্রতিদিনের দোয়া, হাদিস ও কুরআনের আয়াত (তারিখ অনুযায়ী নিজে নিজে বদলায়)
- ৪০টি দোয়া, ৩৬টি হাদিস, ২০টি কুরআনের আয়াত — আরবি, বাংলা উচ্চারণ, অর্থ ও সূত্রসহ
- জিকির কাউন্টার, দৈনিক ও শুক্রবারের আমলের তালিকা
- ছবির কার্ড ডাউনলোড (ফেসবুক পেজে পোস্ট করার জন্য)

## ফাইলের তালিকা

- `index.html` — অ্যাপের মূল ফাইল (সম্পূর্ণ অ্যাপ)
- `assets/` — আইকন, ম্যানিফেস্ট ও অফলাইন সার্ভিস ওয়ার্কার
  - আইকনের ছবিগুলো `.png.b64` আকারে রাখা আছে; APK বানানোর সময় বিল্ড নিজেই সেগুলো আসল `.png` ছবিতে ফিরিয়ে নেয়।
- `content.json` — সব দোয়া, হাদিস ও আয়াতের তথ্য (JSON)
- `capacitor.config.json`, `package.json` — ওয়েব অ্যাপ থেকে Android অ্যাপ বানানোর সেটিংস
- `.github/workflows/build-apk.yml` — APK বানানোর স্বয়ংক্রিয় বিল্ড

আগের একক ফাইল `প্রতিদিনের দোয়া ও হাদিস.html`-ও আগের মতোই রাখা আছে।
